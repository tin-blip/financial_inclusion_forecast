# Event Impact Modeling Methodology

## Approach
- Events modeled as additive effects to baseline trend
- Each event has magnitude, direction, and lag period

## Functional Form
Y(t) = Baseline(t) + Sum(Event_Effect_i(t - lag_i))

## Key Assumptions
- Independent additive effects
- Permanent impacts (not temporary)
- Constant magnitudes over time

## Evidence Sources
- Findex surveys (2011-2024)
- Country case studies
- Expert judgment
- GSMA/IMF data

## Limitations
- Limited historical data
- Survey uncertainty
- Non-linear interactions possible
